# 🧠 SOUL7OS Agent
FastAPI-based ethical AI assistant framework built for easy deployment on Render.

### 🚀 Features
- FastAPI + OpenAI GPT integration
- Real-time risk scoring & compliance filters
- CORS enabled for any frontend (React, UI Bakery, etc.)
- Production-ready with `render.yaml` deployment config

### 🛠 Deployment
1. Upload this repo to Render (Public Git)
2. Add environment variable:  
   `OPENAI_API_KEY=<your_key>`
3. Visit:  
   `https://<your-app-name>.onrender.com/health`
